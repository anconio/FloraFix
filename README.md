FloraFix je aplikacija koja koristi umjetnu inteligenciju za analizu zdravlja biljaka putem fotografija koje korisnici učitavaju. Osnovna funkcionalnost sustava je prepoznavanje potencijalnih problema na biljkama te davanje personaliziranih savjeta za njihovu njegu. Cilj FloraFix-a je pomoći korisnicima da uzgajaju zdrave biljke uz minimalan trud i maksimalnu informiranost.

# Quasar App (florafix)

## Install the dependencies

```bash
pnpm install
# or: yarn/npm/bun install
```

### Start the app in development mode (HMR, error reporting, etc.)

```bash
quasar dev
```

### Format & Lint the files

```bash
pnpm run lint
# or: yarn/npm/bun run lint
```

...or just check formatting & linting:

```bash
pnpm run lint:check
# or: yarn/npm/bun run lint:check
```

### Build the app for production

```bash
quasar build
```

### Customize the configuration

See [Configuring quasar.config.js](https://v2.quasar.dev/quasar-cli-vite/quasar-config-file).
